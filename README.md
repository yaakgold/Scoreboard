# Scoreboard
Code for my scoreboard project using the ESPN public API

## Parts
* **Microcontroller** - Raspberry Pi Pico 2W
* **Display** - 64x32 LED Matrix Display
* **Other Components:**
  * 3 Push Buttons
  * Many wires
  * Display extension cable
  * Power cable for display
